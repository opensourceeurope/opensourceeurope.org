This guide shows how to connect GitHub Sponsors for Organizations to your Collective.

## Choose your starting point

Pick the case that matches your project:

* For a new organization profile, follow [First activation](#first-activation-for-a-github-organization). Have the URL of your Collective hosted by Open Source Europe (OSE) ready. Use an organization owner account with two-factor authentication.
* If you are already sponsored through another host, start with [Move GitHub Sponsors from another host](#move-github-sponsors-from-another-host). A move on Open Collective does not move your Sponsors setup automatically.
* For a personal GitHub account, discuss the arrangement with OSE. The activation steps on this page are for organizations.

The result is a Sponsors profile for your project that uses OSE's fiscal-host route. GitHub reviews the profile first. If the host label or payout setup is unclear, contact OSE before you continue.

Use GitHub Sponsors for your project with OSE as fiscal host and your Collective on Open Collective as the destination for its budget.

## First activation for a GitHub organization

1. Check that your project has a Collective hosted by OSE. The person who configures Sponsors must be an owner of the project’s GitHub organization and have two-factor authentication enabled.
2. Visit [GitHub Sponsors](https://github.com/sponsors), choose **Get sponsored**, and select the project’s own GitHub organization.
3. Select **This organization is using a fiscal host**, then select the host entry for OSE. If the label is unclear, contact OSE before you continue. The public GitHub guide may still show the earlier name, Open Collective Europe.
4. In **Fiscal host project profile URL**, enter your Collective’s Open Collective URL, for example `https://opencollective.com/{COLLECTIVE_SLUG}`. Do not enter OSE’s GitHub organization URL in this field.
5. Complete the project profile and request GitHub approval. Activation depends on GitHub’s review, and there is no promised date for approval.

OSE’s GitHub organization is [opensourceeurope](https://github.com/opensourceeurope). You configure sponsorship for your own project through the fiscal-host route. Do not set up your own Stripe account for that route. If you see a payout setup step you did not expect, contact OSE.

GitHub also supports personal sponsored accounts. This guide covers the setup for organizations. For a personal account, discuss your case with OSE.

## Move GitHub Sponsors from another host

Contact OSE to organize a change from another fiscal host. When you move your Collective on Open Collective, its GitHub Sponsors host does not change automatically. OSE supports you through the process and works with GitHub where needed. Do not assume the migration is complete until the GitHub setup has been confirmed.

## Fees and sponsorship benefits

See the [current OSE fee reference](/docs/faq/general-faqs/#how-much-does-it-cost). GitHub’s own fees are separate. For more information, see GitHub’s [current fee guidance](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes).

If you plan to promise goods, services, or other benefits to sponsors, contact OSE before you commit or receive payment. GitHub’s tier features do not automatically make an arrangement acceptable to OSE.
