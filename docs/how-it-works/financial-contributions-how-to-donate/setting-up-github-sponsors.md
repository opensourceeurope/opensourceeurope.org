Guide to connecting GitHub Sponsors for Organizations to your Collective

## Choose your starting point

* For a new organisation profile, follow [First activation](#first-activation-for-a-github-organisation). Have the URL of your OSE-hosted Collective ready, and use an organisation owner account with two-factor authentication.
* If you are already sponsored through another host, start with [Already using GitHub Sponsors?](#already-using-github-sponsors). A move on Open Collective does not move your Sponsors setup automatically.
* For a personal GitHub account, discuss the arrangement with OSE. The activation steps below are for organisations.

The result is a Sponsors profile for your project that uses OSE's fiscal-host route. GitHub reviews the profile first. If the host label or payout setup is unclear, contact OSE before continuing.

Use GitHub Sponsors for your project with OSE as fiscal host and your Collective on Open Collective as the destination for its budget.

## First activation for a GitHub organisation

1. Your project needs a Collective hosted by OSE. The person configuring Sponsors must be an owner of the project’s GitHub organisation and have two-factor authentication enabled.
2. Visit [GitHub Sponsors](https://github.com/sponsors), choose **Get sponsored**, and select the project’s own GitHub organisation.
3. Select **This organization is using a fiscal host**, then select the host entry for OSE. If the label is unclear, contact OSE before continuing. The public GitHub guide may still show the earlier name, Open Collective Europe.
4. In **Fiscal host project profile URL**, enter your Collective’s Open Collective URL, for example `https://opencollective.com/your-project`. Do not enter OSE’s GitHub organisation URL in this field.
5. Complete the project profile and request GitHub approval. Activation depends on GitHub’s review, and there is no promised date for approval.

OSE’s GitHub organisation is [opensourceeurope](https://github.com/opensourceeurope). You configure sponsorship for your own project through the fiscal-host route. Do not set up your own Stripe account for that route. If you see a payout setup step you did not expect, contact OSE.

GitHub also supports personal sponsored accounts. This guide covers the setup for organisations. For a personal account, discuss your case with OSE.

## Already using GitHub Sponsors?

Contact OSE to organise a change from another fiscal host. Moving your Collective on Open Collective does not automatically update its GitHub Sponsors host. OSE supports you through the process and works with GitHub where needed. Do not assume the migration is complete until the GitHub setup has been confirmed.

## Fees and sponsorship benefits

See the [current OSE fee reference](/docs/faq/general-faqs/#how-much-does-it-cost). GitHub’s own fees are separate. See its [current fee guidance](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes).

If you plan to promise goods, services or other benefits to sponsors, contact OSE before you commit or receive payment. GitHub’s tier features do not automatically make an arrangement acceptable to OSE.
