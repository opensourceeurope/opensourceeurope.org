Guide to connecting GitHub Sponsors for Organizations to your Collective

## Choose your starting point

* **New organisation profile:** follow [First activation](#first-activation-for-a-github-organisation). Have your OSE-hosted Collective URL ready and use an organisation owner account with two-factor authentication.
* **Already sponsored through another host:** start with [Already using GitHub Sponsors?](#already-using-github-sponsors). Moving on Open Collective does not move your Sponsors setup automatically.
* **Personal GitHub account:** discuss the arrangement with OSE; the activation steps below are for organisations.

**Expected outcome:** a project Sponsors profile using OSE's fiscal-host route, subject to GitHub review. If the host label or payout setup is unclear, contact OSE before continuing.

Use GitHub Sponsors for your project with OSE as fiscal host and your Collective on Open Collective as the destination for its budget.

## First activation for a GitHub organisation

1. Your project needs a Collective hosted by OSE. The person configuring Sponsors must be an owner of the project’s GitHub organisation and have two-factor authentication enabled.
2. Visit [GitHub Sponsors](https://github.com/sponsors), choose **Get sponsored**, and select the project’s own GitHub organisation.
3. Select **This organization is using a fiscal host**, then select the host entry corresponding to OSE. If the label is unclear, contact OSE before continuing; the public GitHub guide may still use the earlier name Open Collective Europe.
4. In **Fiscal host project profile URL**, enter your Collective’s Open Collective URL, for example `https://opencollective.com/your-project`. Do not enter OSE’s GitHub organisation URL in this field.
5. Complete the project profile and request GitHub approval. Activation depends on GitHub’s review; no approval deadline is promised.

OSE’s GitHub organisation is [opensourceeurope](https://github.com/opensourceeurope). You configure sponsorship for your own project through the fiscal-host route; do not set up your own Stripe account for that route. If you encounter an unexpected payout setup step, contact OSE.

GitHub also supports personal sponsored accounts. This guide describes organisation setup; discuss a personal-account case with OSE.

## Already using GitHub Sponsors?

Contact OSE to organise a change from another fiscal host. Moving your Collective on Open Collective does **not** automatically update its GitHub Sponsors host. OSE accompanies the process and coordinates with GitHub where necessary. Do not assume the migration is complete until the GitHub setup has been confirmed.

## Fees and sponsorship benefits

See the [current OSE fee reference](/docs/faq/general-faqs/#how-much-does-it-cost). GitHub’s own fees are separate; consult its [current fee guidance](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes).

If you plan to promise goods, services or other benefits to sponsors, contact OSE before commitment or receipt of payment. GitHub’s tier features do not automatically make an arrangement acceptable to OSE.
